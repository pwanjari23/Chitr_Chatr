# 💬 ChitrChatr

> A production-ready real-time chat application supporting instant messaging, typing indicators, emoji reactions, online status, and secure authentication.

---

## 📌 Overview

ChitrChatr is a modern full-stack real-time messaging platform that enables users to communicate instantly using WebSockets. The application focuses on performance, security, and a seamless messaging experience.

It supports one-to-one conversations, live updates, online presence, typing indicators, and responsive design across devices.

---

# ✨ Features

### 🔐 Authentication

- Protected Routes

- Typing Indicators

# 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/pwanjari23/Chitr_Chatr.git
```

### Install

```bash
npm install
```

### Environment Variables

```
PORT=
JWT_SECRET=
DB_NAME=
DB_USER=
DB_PASSWORD=
```

### Run

```bash
npm run dev
```
